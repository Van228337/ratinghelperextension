# Калькулятор рейтинга ЮУрГУ (Rating Helper)

Расширение для браузера, которое показывает текущий рейтинг по дисциплине в журнале ЮУрГУ (`online.susu.ru`), моделирует итоговые баллы и помогает выйти на желаемую оценку.

## Возможности

1. **Целевой калькулятор («Сколько нужно набрать»)**:
   - Автоматически рассчитывает, сколько баллов нужно набрать за оставшиеся несданные работы для получения **«Зачёта / 3» (59.01%)**, **«Хорошо» (74.01%)** или **«Отлично» (84.01%)**.
   - В один клик позволяет применить смоделированные баллы в форму.
2. **Прогноз диапазона (Мин / Текущий / Макс)**:
   - Показывает гарантированный минимум (если больше ничего не сдавать) и максимально возможный потенциал (если сдать все оставшиеся работы на 100%).
3. **Быстрые действия**:
   - «⚡ Остаток на max» — выставляет максимум только несданным работам.
   - «💯 Всё на max» — заполняет 100% всем работам.
   - «🔄 Сброс» — моментально возвращает фактические баллы из журнала.
4. **Академическая оценка по шкале ЮУрГУ**:
   - Автоматический расчёт оценки с цветным бейджем и наглядным прогресс-баром.
   - Подсказка, сколько процентов не хватает до следующей оценки.
5. **Учёт экзамена / дифзачёта**:
   - Переключатель режима автомата и сдачи экзамена.
   - Формула: `60% текущий контроль + 40% экзамен + бонус`.
6. **Встраивание виджета прямо на страницу журнала**:
   - Аккуратная плашка с текущим рейтингом отображается прямо рядом с названием предмета в `online.susu.ru`.
7. **Сводка по семестру (Дашборд)**:
   - Общий список открытых предметов с расчётом среднего балла за семестр и отслеживанием задолженностей.
8. **Сохранение смоделированного плана**:
   - Запоминает введённые баллы как ваш персональный черновик/план с возможностью сброса к факту.
9. **Гибкие настройки**:
   - Экран настроек ⚙️ позволяет включать и выключать каждую функцию по отдельности.
10. **Тёмная и светлая темы**.

---

## Шкала оценок ЮУрГУ

* **Менее 59.01%** — Незачёт / Долг
* **59.01% – 74.00%** — Удовлетворительно (3) / Зачтено
* **74.01% – 84.00%** — Хорошо (4)
* **84.01% и выше** — Отлично (5)

---

## Формулы расчёта

### Текущий контроль (на автомат)
```text
Рейтинг = Σ(Процент_работы × Вес) / Σ(Весов) + Бонус
```

### С учётом экзамена
```text
Итог = (Текущий_контроль × 0.6) + (Экзамен_% × 0.4) + Бонус
```

## Установка

1. Откройте страницу расширений браузера (`chrome://extensions` в Chrome/Edge/Яндекс Браузере).
2. Включите **Режим разработчика** (Developer mode).
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку с расширением.
5. Для обновления после изменений нажмите иконку **«Обновить»** (круговая стрелка) на карточке расширения.
