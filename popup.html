Настройки функций

🎯 Калькулятор целей (до 3, 4, 5) Рассчитывает, сколько баллов нужно набрать за оставшиеся несданные работы (или на экзамене) для получения желаемой оценки, с кнопкой автоподстановки баллов.
📊 Прогноз диапазона (Мин / Макс) Показывает гарантированный минимум (если больше ничего не сдавать) и максимальный предел (если сдать всё оставшееся на 100%).
⚡ Кнопки быстрых действий Быстрые кнопки: «Остаток на max» (заполняет только нули), «Всё на max» (100% всем работам) и «Сброс» (возврат реальных баллов из журнала).
🏅 Оценка по шкале БРС Определяет текущую оценку (Незачёт, 3, 4, 5) по официальным порогам БРС (59.01% / 74.01% / 84.01%), отображает цветной бейдж, шкалу и подсказку, сколько не хватает до следующего балла.
📝 Учёт экзамена (дифзачёта) Позволяет смоделировать сдачу экзамена по формуле: 60% текущий контроль + 40% экзамен + бонус.
🌐 Информационный виджет на странице Встраивает удобную плашку с потенциалом и текущим баллом прямо на сайт online.susu.ru рядом с названием предмета.
📚 Сводка по семестру (Дашборд) Экран со всеми посещёнными предметами, расчётом общего среднего балла за семестр для стипендии и контролем задолженностей.
💾 Сохранение плана (Черновик) Запоминает смоделированные вами баллы в памяти браузера, чтобы при повторном открытии предмета вы видели свой запланированный результат.

Информация

Шкала оценок БРС:

  • Менее 59.01% — Незачёт / Долг (2)
  • 59.01% – 74.00% — Удовлетворительно (3) / Зачтено
  • 74.01% – 84.00% — Хорошо (4)
  • 84.01% и выше — Отлично (5)

Формула текущего контроля:
Рейтинг = Σ(Процент_работы × Вес) / Σ(Весов) + Бонус

Формула с экзаменом:
Итог = Текущий × 0.6 + Экзамен × 0.4 + Бонус

Вы можете редактировать баллы по каждой работе и настраивать отображение функций в меню настроек ⚙️.
