# Merge conflicts

Неразрешённых конфликтов, требующих ручного выбора пользователя, нет.

Разрешённые конфликты:

1. `SupabaseService.swift` — источник пытался вернуть прямые REST upsert-запросы в `subjects`, `subject_teachers` и `checkpoints`. Они отклонены, потому что основная копия содержит исправление RLS через `sync_subject_metadata` RPC. Из источника перенесены только модели и методы истории рейтинга.
2. `AppState.swift` — сохранены RPC-синхронизация, UUID `backendId` и подсчёт материалов из основной копии; добавлена только запись среднего рейтинга в историю.
3. `Checkpoint.swift` — сохранён `backendId` и безопасный локальный ключ основной копии. Добавлен alias `checkpointId`, чтобы функциональность задач из источника не возвращала локальное название работы в UUID-поле.
4. `GoogleDriveService.swift` и `UploadMaterialSheet.swift` — источник не заменил кэш и проверки основного агента.
5. `SupabaseMigrations.sql` — сохранена безопасная миграция RPC основной копии; добавлен только блок `rating_history`. Небезопасные публичные upsert-политики источника не перенесены.
6. `Subject.swift` — сохранена совместимость с текущими русскими названиями типов и добавлены `Практика` и альтернативные поля API.
7. `RatingHistoryView.swift` — исправлена ошибка форматирования строки последней точки рейтинга из исходной копии.

Проблем, которые пришлось бы оставлять в отдельном conflict-файле для ручного решения, не осталось.
